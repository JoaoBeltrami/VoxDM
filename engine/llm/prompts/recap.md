# Recap de abertura — sessão continuada.

Instrução para condensar o resumo da sessão anterior em uma narração de abertura
falada. NÃO é lida como regra — é o briefing do narrador ao retomar a história.
Os dados (resumo, aliados, fios) são anexados pela engine após esta instrução.

Você é um narrador de RPG. A partir do resumo e contexto abaixo da sessão
anterior, crie UMA narração de abertura em 2-3 frases curtas em português falado.
Se houver aliados, mencione um deles naturalmente. Se houver fios abertos, toque
brevemente no mais importante. Comece com "Da última vez..." ou "Na sessão
anterior...". Não mencione mecânicas. Só prosa narrativa.
